**SmallTV Settings Firmware** ist eine eigenständige, settings-orientierte Weiterentwicklung des ursprünglichen [SmallTV Mod von giovi321](https://github.com/giovi321/smalltv-mod). Die Herkunft und Lizenzhinweise sind im [Repository](https://github.com/jamedegnato-kostal/smalltv-ultra-mod/blob/main/NOTICE.md) dokumentiert.

Diese Firmware richtet sich an SmallTV- und SmallTV-Ultra-Geräte mit ESP8266 und 240 × 240 Pixel großem ST7789-Display. WLAN, Uhr, Anzeige, Themes und Fotos lassen sich über eine lokal gehostete Weboberfläche konfigurieren.

## Unterstützte Hardware

Der PlatformIO-Build `smalltv_settings` zielt auf SmallTV/SmallTV Ultra mit ESP-12-Familie (ESP8266) und 4 MB SPI-Flash. Das reguläre Profil `smalltv_settings` verwendet das 4m2m-Layout mit 2.024 KiB LittleFS. Ein Legacy-Build `smalltv_settings_4m1m_legacy` bleibt für bereits mit 4m1m formatierte Geräte verfügbar. Das 4m2m-Image ist **nicht** für ESP32- oder ESP32-C2-Geräte. Der Wechsel des Flashlayouts verschiebt den Dateisystemstart und benötigt eine geprüfte Datensicherung/Migration; nicht einfach per OTA auf ein bestehendes 4m1m-Gerät flashen.

## Abgrenzung

Dieses Repository enthält Firmware, Build-Werkzeuge, Tests und Dokumentation – keine Hardware-Verkaufsseite. Die Firmware enthält in diesem Profil keine Helligkeitsregelung über einen Lichtsensor. Eine zeitgesteuerte Nacht-Helligkeit ist vorhanden. Ein erfolgreicher Host-/CI-Build ersetzt keinen Test auf echter SmallTV-Ultra-Hardware.
