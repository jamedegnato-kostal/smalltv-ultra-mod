# Web UI previews

These preview illustrations show the structure and visual language of the embedded
SmallTV Stable web interface. Device values and playlist entries are sample data;
the firmware serves the actual interactive interface from `src/webui_stable.h`.

- `webui-overview.svg`: device overview and quick status cards.
- `webui-playback.svg`: mixed photo/theme playlist, ordering and playback controls.

The interface is responsive and is served locally by the device. No cloud service
is required for the web UI itself.
